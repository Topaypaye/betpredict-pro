📘 Complete Mathematical & Algorithmic Model Guide

Multi-Sport Quantitative Engine

🌟 Two-Tier Modeling Architecture

BetPredict Pro uses a rigorous two-tier quantitative framework that unifies independent, fundamental statistical models with de-vigged bookmaker market consensus. Rather than relying blindly on public odds or naive statistics, the system evaluates both tiers separately before blending them.

Tier 1: Pure Statistical Model (P_stats)

Completely independent of bookmaker lines. Evaluates historical Elo ratings, expected scoring margins (xG / PPG), Morey Pythagorean expectations, recent form momentum, home/road splits, venue fatigue, and real-time player injuries.

Tier 2: De-Vigged Market Consensus (P_market)

Captures the collective wisdom of closing and live lines across sharp bookmakers (DraftKings, Winamax.fr, Pinnacle). The bookmaker's profit margin (the "vig") is stripped using power and multiplicative normalization to reveal true market implied probabilities.

The Blending Equation

The final prediction balances independent statistical edge with market efficiency:

P_final = (1 - Market_Share) * P_stats + Market_Share * P_market // Default Market Shares: // Football: 15% Market / 85% Statistical Model // NBA: 30% Market / 70% Statistical Model // Tennis: 35% Market / 65% Statistical Model
🛡️ The Injury-Divergence Overrule Rule: Bookmaker market odds frequently suffer from "reputation lag" and casual betting inertia when major superstars are ruled out late. When the statistical model projects a team to lose (P_stats < 0.50) due to severe net star injuries (≥ 2.5 pts), but public odds still favor them (P_market > 0.50), the system automatically discounts the bookmaker line and trusts the Statistical Model.

🏀 NBA Quantitative Methodology

The NBA engine utilizes five statistical sub-components combined with automated point-in-time sequential processing, eliminating look-ahead bias and blowout distortion.

1. Point-in-Time Sequential FiveThirtyEight Elo (Weight: 32%)

Elo is updated match-by-match chronologically. Every past game is evaluated using only the Elo ratings and records established prior to that specific kickoff.

MOV_Multiplier = (|Actual_Margin| + 3.0)^0.8 / (7.5 + 0.006 * |Elo_Diff|) Shift = 20.0 * MOV_Multiplier * (Actual_Win - Expected_Win) Elo_New = Elo_Old + Shift // Parameters: // K-Factor = 20.0 // Home-Court Advantage (HCA) = +50.0 Elo (~2.2 points expected margin) // Offseason Mean Reversion = 45% pull toward 1500 league average

2. Net Rating & Projected Score with Blowout Cap (Weight: 28%)

Computes expected offensive and defensive PPG, smoothed with 14-game prior shrinkage and an 18-point Margin of Victory (MOV) cap to prevent isolated blowouts from distorting ratings.

Proj_Home = 0.5 * (Off_Home + Def_Away) + 0.5 * HCA_pts + 0.5 * Total_Situational_pts Proj_Away = 0.5 * (Off_Away + Def_Home) - 0.5 * HCA_pts - 0.5 * Total_Situational_pts Proj_Margin = Proj_Home - Proj_Away P(Home) = 0.5 * [ 1 + erf( Proj_Margin / (11.5 * sqrt(2)) ) ] // Standard deviation of NBA game margin: sigma = 11.5 points

3. Morey Pythagorean Expectation & Log5 (Weight: 14%)

Uses Daryl Morey's empirically calibrated NBA exponent (13.91). Game-day absences directly subtract from projected scoring capability:

Pyth_Win% = (Points_For^13.91) / (Points_For^13.91 + Points_Against^13.91) Log5_P(Home) = [ Pyth_H * (1 - Pyth_A) * 0.54 ] / [ Num + (1 - Pyth_H) * Pyth_A * 0.46 ] // Calibrated to modern NBA baseline home win rate of ~54.0%

4. Form (Streak Momentum) & Home/Road Splits (Weight: 14% + 12%)

Form models last-10 game momentum augmented with an active streak bonus (capped at ±5 games). Home/Road isolates home win percentage in home games vs road win percentage in away games.

⚽ European Football Quantitative Methodology

European soccer utilizes a multi-variable Poisson framework, modeling 3-way outcomes (Home Win, Draw, Away Win) alongside goal markets (Over/Under 2.5).

1. Dixon-Coles Bivariate Poisson Matrix (Weight: 21%)

Independent Poisson models underestimate draws. The Dixon-Coles adjustment applies a low-score correlation parameter (ρ = -0.11) across a 10×10 scoreline matrix:

Lambda_Home = Attack_Home * Defense_Away * Home_Pitch_Factor Mu_Away = Attack_Away * Defense_Home P(Score = i, j) = Poisson(i, Lambda) * Poisson(j, Mu) * Tau_rho(i, j) // Tau adjustment increases 0-0 and 1-1 draws while lowering 1-0 and 0-1

2. Dual xG and Real Goal EWMA Engines (Weight: 21% + 22%)

Expected Goals (xG) strip finishing luck to evaluate underlying chance quality. Ratings update with an Exponentially Weighted Moving Average (α = 0.085, ~12 match memory).

3. Football FiveThirtyEight Elo (Weight: 23%)

Operates with K = 22.0, Home Field Advantage of +46 Elo points, and goal-margin multipliers (1.0 for 1 goal, 1.5 for 2 goals, 1.75 for 3+ goals).

🎾 ATP & WTA Tennis Quantitative Methodology

Tennis is an individual, non-draw sport heavily dependent on court surface, ranking differentials, and physical fatigue.

1. Dual Surface Elo & Variable K-Factor (Weight: 26% Surface + 42% Global)

Maintains distinct Elo ratings per surface (Hard, Clay, Grass, Carpet) blended 50/50 with global Elo. FiveThirtyEight variable K-factor adjusts for experience:

K = 250.0 / (Matches_Played + 5.0)^0.40 // Debutants have high K (~130), allowing rapid discovery. // Seasoned veterans have low K (~25), preventing knee-jerk overreactions.

2. Official Ranking Log-Ratio Model (Weight: 20%)

P(Player A) = 1.0 / [ 1.0 + exp( -0.95 * ln( Rank_B / Rank_A ) ) ] // A rank #5 player facing rank #50 produces an expected win rate of 88.9%

3. Physical Fatigue & Cumulative Sets Penalty

Deep runs in back-to-back tournaments drain endurance. Every extra set played in the last 7 days compared to the opponent penalizes win probability by -1.2 percentage points (capped at -6%).

💰 Value Betting Intelligence & Staking Strategy

A high win probability does not constitute a profitable bet if the odds offered are worse than fair value. BetPredict Pro flags positive Expected Value (+EV) bets and suggests mathematically sound stake sizing.

1. Expected Value (Edge %)

Expected_Value_Edge = (Model_Probability * Decimal_Odds) - 1.0 // Example: // Model Probability: 40% (0.40) // Bookmaker Odds: 2.80 // Edge = (0.40 * 2.80) - 1.0 = +12.0% Value Edge

2. Quarter-Kelly Criterion Bankroll Allocation

Full Kelly maximizes growth but suffers from extreme variance. The model implements Quarter-Kelly (0.25×), capping maximum risk at 5.0% of total bankroll per position:

b = Decimal_Odds - 1.0 f_star = [ P * b - (1 - P) ] / b Stake_Pct = min( 5.0%, 0.25 * f_star * 100 )
